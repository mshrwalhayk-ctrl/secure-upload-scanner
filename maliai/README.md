# مساعد المحاسب — MaliAI

مساعد ذكاء اصطناعي عربي بالكامل داخل مايكروسوفت إكسل، مبني لمحاسب مالي.
بتحكي معه بالعربي وبيشتغل على الشيت مباشرة: بيكتب المعادلات، بينظّف البيانات،
بيدقّق الأرقام كمراجع محترف، بيعمل التقارير والرسوم، وبيشغّل ماكرو بعد موافقتك.

## نسختان

| | excel-addin-taskpane | excel-addin-vba |
|---|---|---|
| الشكل | زر في تبويب الصفحة الرئيسية + **لوحة مرصوفة** على جنب الشيت | تبويب خاص + نافذة عائمة |
| التقنية | Office.js | VBA (.xlam) |
| يشتغل على | ويندوز + ماك + إكسل ويب | ويندوز فقط |
| تشغيل ماكرو VBA | ✖ مستحيل تقنياً | ✔ |
| قيود CORS | نعم — استخدم OmniRoute | لا — أي مزوّد بيشتغل |
| التركيب | GitHub Pages + تسجيل manifest | INSTALL.cmd ← دبل كليك |

النسختان بتتركّبوا مع بعض بدون تعارض.

## المحرّك

- **استدعاء الأدوات الأصلي (Function Calling)** — النموذج ما بيكتب JSON بإيده،
  المزوّد بيرجّع الاستدعاء منظّماً ومضمون الشكل. وضع نصي احتياطي للنماذج القديمة.
- **الحساب** بيمرق كله على محرّك إكسل نفسه — النموذج ممنوع يحسب بعقله.
- **تراجع** لآخر ٢٠ تعديل، ونسخة احتياطية تلقائية قبل أي ماكرو.

## أدوات المدقق المحترف

| الأداة | شو بتعمل |
|---|---|
| trial_balance | ميزان المراجعة: المدين = الدائن؟ وبيقترح سبب الفرق |
| benford_analysis | تحليل بنفورد لكشف الأرقام المفبركة أو المُدخلة يدوياً |
| find_gaps | فجوات تسلسل الفواتير والشيكات والسندات |
| reconcile | مطابقة كشف البنك مع الدفتر وتحديد الفروقات بالضبط |
| aging_analysis | أعمار الذمم مع تنبيه إذا المتقادم تجاوز ٢٥٪ |
| duplicate_payments | كشف المدفوعات المكررة |
| stats_summary | إحصاء + كشف الأرقام المخزّنة كنص |
| check_column | تدقيق عمود: أرقام كنص، مسافات، أخطاء، مكررات |
| goal_seek | البحث عن هدف |

وكمان: قراءة، كتابة قيم ومعادلات، تنسيق، فرز، حذف مكرر، بحث، رسوم بيانية، وماكرو VBA.

## المزوّدون

الافتراضي [OmniRoute](https://github.com/diegosouzapw/OmniRoute) — بوابة محلية بتوحّد
٣٥٢ مزوّد و١٢٠٠+ نموذج، بتضغط النص ١٥–٩٥٪، وبتشتغل **بدون أي مفتاح**:

    npm i -g omniroute
    omniroute

وكمان مدعوم مباشرة: NVIDIA NIM، OpenRouter، Groq، Anthropic، وأي رابط مخصّص.

التفاصيل الكاملة في README-AR.md داخل كل مجلد.
